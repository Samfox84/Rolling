Rooms

Studio settings — email, backup drive, relay, transcripts, clean-up files

📧 Email when files are ready

Uses your own mail server (e.g. Mailcow). For Mailcow on this same machine: host 127.0.0.1, port 587, and a mailbox's address + password. Who gets emailed is set per room on its Recordings page.

💾 Backup drive

Every finished take is copied here automatically. Must be a different disk (e.g. your USB drive). Leave empty for no backup.

☁️ Cloud backup

Every finished take is also uploaded to Google Drive, Dropbox, OneDrive or similar, in the background. Set up your account once on the server with rclone config — see the step-by-step guide. Leave empty for no cloud backup.

🛰 Relay for strict networks (Cloudflare TURN — free)

Lets guests on locked-down office/hotel Wi-Fi still see and hear everyone. Cloudflare dashboard → Realtime → TURN Server → Create, then paste the Key ID and API token here. (Recordings upload fine without this.)

📝 Transcripts

Made on this server (whisper.cpp) — free and private. Runs quietly in the background while you record, so it's nearly done when you press Stop.

🧽 Clean-up files

After each take, a cleaned copy of every voice is made next to the untouched recordings (those are always kept exactly as recorded). The Producer mix uses the cleaned voices with your live fader moves. Change these any time and press 🧽 Clean again on a take.
